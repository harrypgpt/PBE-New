# @pbe/science-core

Reserved for PBE's deterministic (L1) and statistical (L2) methods.

- **Pure:** no database, network, file-system or clock access. ESLint enforces this.
- **TypeScript only** (ADR-022).
- **Empty in Stage 1.** The first method arrives in Stage 8 (units), and only with an approved specification in `docs/methods/` and cited test vectors.
